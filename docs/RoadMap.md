## 📋 What You Can Do With the Token RIGHT NOW

1. **Send and receive PNJC** on the Polygon network using any wallet (MetaMask, Rabby, etc.)
2. **Burn (destroy) your own tokens** via the `burn()` function
3. **Approve spending via signature** (Permit) without paying gas for a separate `approve()` transaction
4. **Inspect the code and contract** on Polygonscan
5. **Hold, transfer, check balances** — everything a standard ERC-20 token does

## 🎯 Core Utility and Project Mission

**PanjoCoin is built to fund real-world charity.**

### Goal #1 (Already Active)

Funding the **ClownCare** project at the **M. Iashvili Central Children's Hospital** (Tbilisi, Georgia).

Funds are directed toward:
- Supporting children undergoing treatment
- Creating a comfortable emotional environment in the hospital
- Assisting medical staff with organizing activities for young patients

### Goal #2 (Future — After Project Growth)

Once the PanjoCoin project reaches sufficient market capitalization and community support, additional initiatives will be added:

- **Expanding ClownCare** to all children's hospitals in Georgia
- **Funding treatment for seriously ill children**
- **Supporting children with rare (orphan) diseases** across Georgia
- **Purchasing modern medical equipment**
- **Procuring medical supplies and pharmaceuticals**

> ⚠️ **Important:** The second phase will begin **only after PNJC's value and liquidity allow meaningful amounts to be allocated without harming token holders**. Timelines depend entirely on the project's growth.
