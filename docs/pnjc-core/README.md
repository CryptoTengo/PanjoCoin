# 🟢 PNJC Core Protocol

PNJC-Core is a fixed-supply ERC-20 token system with modular ecosystem components including liquidity management, vesting, and distribution mechanisms.

---

## 📌 Key Properties

- Fixed supply: 1,000,000,000,000 PNJC  
- No mint function  
- No upgradeability  
- No on-chain governance (currently multisig-based control)  
- Modular ecosystem design  

---

## 📦 Modules

- PNJC Token (ERC20 + Permit + Burnable)  
- Liquidity Lock Module  
- Vesting Vault  
- Airdrop Module  
- Treasury (Multisig-controlled)  

---

## ⚠️ Status

This is a **protocol core implementation (Phase 1)**.

- Governance module is not implemented at this stage  
- System is currently operated via multisig and off-chain coordination
