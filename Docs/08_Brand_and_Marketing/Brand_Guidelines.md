## 1. Purpose

This document establishes the official brand guidelines for the PanjoCoin (PNJC) ecosystem.

Its purpose is to ensure that all communications, visual assets, documentation, and community materials present a consistent, professional, and trustworthy identity across all platforms.

These guidelines apply to:

- Team members;
- Contributors;
- Partners;
- Community moderators;
- Designers;
- Developers;
- AI-assisted content generation (where applicable).

## 3. Brand Vision

PanjoCoin's brand vision:

> To build a trusted global blockchain ecosystem where digital assets, community participation, decentralised governance, and real‑world social impact create sustainable value for users worldwide.

The brand should communicate:

- **Innovation** — cutting-edge Web3 technology;
- **Trust** — transparent, ownerless, and secure infrastructure;
- **Community** — participation and collaboration;
- **Impact** — measurable social and charitable outcomes.

## 7. Brand Voice

Communications should be:

| Style | Description |
| :--- | :--- |
| **Clear** | Easy to understand. |
| **Accurate** | Factually correct and verifiable. |
| **Respectful** | Professional and courteous. |
| **Educational** | Informative and helpful. |
| **Confident** | Strong but not arrogant. |
| **Accessible** | Understandable to non-technical audiences. |

## 8. Tone of Voice

**Recommended Tone:**

| Tone | Description |
| :--- | :--- |
| **Helpful** | Provide value to the audience. |
| **Positive** | Constructive and optimistic. |
| **Calm** | Measured and professional. |
| **Transparent** | Open and honest. |
| **Professional** | Credible and trustworthy. |

**Avoid:**

- Hype and over-promotion;
- Fear of missing out (FOMO);
- Unrealistic promises;
- Sensationalism;
- Financial guarantees;
- Misleading statements.

## 12. Logo Usage

The official logo should:

- Maintain original proportions;
- Remain clearly visible;
- Use approved versions only;
- Be displayed with sufficient spacing.

**Do not:**

- Stretch or distort the logo;
- Rotate the logo;
- Modify colours without approval;
- Add visual effects that reduce clarity.

---

## 13. Typography

Typography should prioritise readability.

**Recommended characteristics:**

- Modern;
