## 1. Overview

This document defines the **Impact Framework** of PanjoCoin (PNJC).

The purpose of the PNJC Impact Framework is to create a transparent and measurable system for evaluating, recording, and rewarding positive contributions within the ecosystem.

The framework connects:

- Blockchain technology;
- Social impact initiatives;
- Community participation;
- Charity programs;
- Proof of Kindness;
- ESG principles.

The PNJC Impact Framework is based on:

```
Positive Action
        +
Verification
        +
Measurement
        +
Transparency
        +
Recognition
        =
Social Impact Value
```

---

## 2. Impact Mission

The mission of the PNJC Impact Framework:

> To transform positive human actions and social contributions into measurable digital impact records using blockchain technology.

The framework aims to create a new model where:

- Kindness becomes measurable;
- Contributions become verifiable;
- Communities become empowered;
- Impact becomes transparent.

## 4. Core Principles

### 4.1. Transparency

All verified impact activities should have:

- Public records (on-chain);
- Verification history;
- Clear methodology;
- Traceable outcomes.

### 4.2. Verification

Impact must be based on:

- Evidence;
- Community validation;
- Partner confirmation;
- Trusted verification processes.

### 4.3. Fairness

The system should reward:

- Genuine contributions;
- Positive behaviour;
- Long-term participation.

### 4.4. Sustainability

Impact programs must consider:

- Long-term benefits;
- Responsible resource usage;
- Community value.
