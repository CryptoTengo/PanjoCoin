# 1. Overview

This document defines the Charity Program framework of PanjoCoin (PNJC).

The PNJC Charity Program is designed to connect blockchain technology with measurable real-world social impact.

The program creates a transparent ecosystem where:

- Donations can be publicly verified
- Social initiatives can be measured
- Communities can participate
- Positive actions can be recognized


The Charity Program is based on:


Blockchain Transparency

Verified Impact

Community Participation

Long-Term Social Value
