## 1. Overview

This document defines the **Charity Program** framework of PanjoCoin (PNJC).

The PNJC Charity Program is designed to connect blockchain technology with measurable real-world social impact.

The program creates a transparent ecosystem where:

- Donations can be publicly verified (on-chain);
- Social initiatives can be measured;
- Communities can participate;
- Positive actions can be recognised.

The Charity Program is based on:

| Principle | Description |
| :--- | :--- |
| **Blockchain Transparency** | All transactions publicly verifiable. |
| **Verified Impact** | Charitable initiatives must be verified and measurable. |
| **Community Participation** | Community input and oversight. |
| **Long-Term Social Value** | Sustainable, long-term social impact. |
