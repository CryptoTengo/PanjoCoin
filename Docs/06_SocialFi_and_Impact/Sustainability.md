## 1. Overview

This document defines the **sustainability framework** of PanjoCoin (PNJC).

The purpose of this document is to describe how PNJC aims to build a long-term, resilient, and responsible Web3 ecosystem.

Sustainability in PNJC includes:

- Economic sustainability;
- Technological sustainability;
- Social sustainability;
- Governance sustainability;
- Environmental responsibility.

The PNJC sustainability model is based on:

| Principle | Description |
| :--- | :--- |
| **Long-Term Vision** | 24-month roadmap with phased development. |
| **Responsible Growth** | Controlled releases and utility-driven demand. |
| **Real Utility** | Gaming (ONE+), charity (ClownCare Bridge), governance (DAO). |
| **Community Participation** | DAO governance and community incentives. |
| **Transparent Management** | On-chain verification, multisig controls. |

## 4. Economic Sustainability

### 4.1. Fixed Supply Model

PNJC uses a fixed supply:

| Property | Value |
| :--- | :--- |
| **Total Supply** | 1,000,000,000,000 PNJC |
| **Minting** | Disabled |
| **Supply Increase** | Impossible |

**Characteristics:**
- No unlimited inflation;
- No uncontrolled minting;
- Transparent allocation;
- Predictable supply model.

### 4.2. Utility-Driven Economy

Long-term value creation depends on:

- Ecosystem usage (gaming, charity, governance);
- Platform services (ONE+ gaming platform);
- SocialFi participation (Proof of Kindness);
- Community adoption.

**The objective:**

```
Real Usage
        ↓
Ecosystem Activity
        ↓
Sustainable Demand
```

### 4.3. Treasury Sustainability

Treasury allocation:

| Category | Share | Amount (PNJC) | Control |
| :--- | :--- | :--- | :--- |
| **Operational Treasury** | 12% | 120,000,000,000 | 3/5 Multisig |
| **DAO Treasury** | 10% | 100,000,000,000 | DAO (Q4 2026) |
| **Charity Reserve** | 5% | 50,000,000,000 | Public wallet |

Treasury supports:
- Development;
- Security (audits);
- Partnerships;
- Marketing;
- Ecosystem growth.

### 4.4. Controlled Token Release

Sustainability is supported through:

- Vesting schedules (Team: 6-month cliff + 12-month vesting; Founder: 12-month cliff + 24-month vesting);
- Unlock management (5% annual release);
- Treasury controls (3/5 multisig);
- Community distribution limits.

### 4.5. Liquidity Sustainability

Liquidity strategy focuses on:

- Healthy market access (Uniswap V2);
- Long-term liquidity availability (12-month lock);
- Transparent liquidity management.

**Liquidity allocation:** 500,000,000,000 PNJC (50%) — locked for 12 months.

### 5.4. Security Sustainability

## 10. Sustainability Risk Management

| Risk | Impact | Mitigation |
| :--- | :--- | :--- |

| **Financial Pressure** | Development slowdown | Treasury planning, controlled expenses, sustainable budgeting. |

| **Governance Centralisation** | Reduced community trust | Multisig (3/5), DAO transition (Q4 2026), transparency. |
