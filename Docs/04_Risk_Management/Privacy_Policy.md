# 2. Important Notice Regarding Blockchain Data

PanjoCoin operates on public blockchain infrastructure.

Blockchain transactions are:

transparent;
publicly accessible;
permanently recorded;
generally irreversible.

When users interact with PNJC smart contracts:

wallet addresses;
transaction history;
token balances;
blockchain activity

may become publicly visible.

PanjoCoin cannot delete or modify information stored directly on public blockchains.

Users should understand that blockchain technology provides transparency by design.
