## 16. PNJC Token and Blockchain Transparency

The PNJC token contract (`0x51ba27A6EB41D879B03ed28eD0A5d6a2982B0BcF`) is:

- **Ownerless** (`owner = address(0)`) — no administrative control;
- **Non-upgradeable** — immutable once deployed;
- **Zero tax** — 0% on all transactions;
- **Fixed supply** — 1 trillion PNJC, no minting;
- **Verified** — source code verified on PolygonScan (Exact Match);
- **Open-source** — public GitHub repository.

**Important:** All blockchain transactions are public and cannot be deleted. Users should be aware that their wallet addresses and transaction history are permanently recorded on the Polygon blockchain.
