## 1. Overview

This document outlines the **Anti-Money Laundering (AML)** and **Countering the Financing of Terrorism (CFT)** policy of PanjoCoin (PNJC). The purpose of this policy is to establish a framework for preventing and detecting money laundering, terrorist financing, and other illicit activities within the PanjoCoin ecosystem.

PanjoCoin is committed to:

| Commitment | Description |
| :--- | :--- |
| **Compliance** | Adhering to applicable AML/CFT laws and regulations. |
| **Transparency** | Maintaining transparent operations and record-keeping. |
| **Risk Management** | Identifying, assessing, and mitigating AML/CFT risks. |
| **Cooperation** | Cooperating with relevant authorities and regulatory bodies. |

---

## 2. Policy Statement

PanjoCoin and its team are committed to:

- Preventing the use of PNJC for money laundering, terrorist financing, or other illicit activities;
- Complying with all applicable laws and regulations in the jurisdictions where we operate;
- Implementing effective AML/CFT controls and procedures;
- Maintaining high standards of transparency and accountability;
- Conducting risk assessments and implementing appropriate mitigation measures.

**Important:** While PanjoCoin is a decentralised project operating on the Polygon PoS blockchain with an ownerless, non-upgradeable token contract, we recognise the importance of AML/CFT compliance and are committed to implementing appropriate measures where feasible.

## 4. AML/CFT Risk Assessment

### 4.1. Risk Categories

| Risk Category | Description | Mitigation |
| :--- | :--- | :--- |
| **Jurisdictional Risk** | Users from high-risk or sanctioned countries. | Restricted countries list, IP blocking where possible. |
| **Product Risk** | Cross-border transfers, pseudonymous nature. | Transparent blockchain (PolygonScan), transaction monitoring. |
| **Customer Risk** | High-value transactions, complex structures. | Transaction monitoring, public blockchain verification. |
| **Delivery Channel Risk** | Decentralised nature limits control. | Voluntary compliance, education, community reporting. |

### 4.2. Identified AML/CFT Risks

| Risk | Likelihood | Impact | Mitigation |
| :--- | :--- | :--- | :--- |
| **Use for Illicit Activities** | Medium | High | Transaction monitoring, public blockchain, community reporting. |
| **Sanctions Violations** | Low | High | Restricted countries list, sanctions screening. |
| **Pseudonymity Exploitation** | Low | Medium | Transparent blockchain (no privacy features). |
| **Cross-Border Movements** | Medium | Medium | On-chain monitoring, exchange cooperation. |

### 4.3. Sanctions Compliance

## 5. Customer Due Diligence (CDD)

### 5.1. Decentralised Context

PanjoCoin is a decentralised project operating on the Polygon blockchain. As such:

- **No KYC is required** for DEX trading (Uniswap V2) or wallet-to-wallet transfers;
- **No personal information is collected** for on-chain interactions;
- **No central authority controls** user accounts or transactions;
- The token contract is **ownerless** (`owner = address(0)`) with **no administrative functions**.

### 5.2. Voluntary CDD Measures

Despite the decentralised nature, the project encourages:

| Measure | Description |
| :--- | :--- |
| **Self-Attestation** | Users confirm they are not from restricted jurisdictions. |
| **Community Reporting** | Reports of suspicious activity are investigated. |
| **Transparent Operations** | All major transactions are on-chain and verifiable via PolygonScan. |
| **Official Channels** | Users are encouraged to use official communication channels. |

### 5.3. CEX Requirements

For centralised exchange listings (future potential), users may be subject to:

| Requirement | Description |
| :--- | :--- |
| **KYC Verification** | Identity verification as per exchange requirements. |
| **Source of Funds** | Explanation of funds origin for large deposits. |
| **Transaction Limits** | Limits on withdrawals and deposits. |

## 6. Transaction Monitoring

### 6.1. Monitoring Framework

PanjoCoin implements monitoring of:

| Activity | Description |
| :--- | :--- |
| **Large Transactions** | Unusual or large value transfers (on-chain). |
| **Complex Transactions** | Multiple transactions with no clear economic purpose. |
| **High-Risk Jurisdictions** | Transactions involving restricted countries. |
| **Suspicious Patterns** | Unusual trading patterns or behaviours. |

### 6.2. Monitoring Tools

| Tool | Purpose |
| :--- | :--- |
| **PolygonScan** | Public transaction monitoring and verification. |
| **Blockchain Analytics** | Advanced analytics (planned). |
| **Community Reporting** | User-reported suspicious activity. |
| **Internal Review** | Team review of unusual activity. |

### 6.3. Suspicious Activity Indicators

| Indicator | Description |
| :--- | :--- |
| **Unusual Volume** | Transactions significantly above normal patterns. |
| **Structuring** | Breaking large transactions into smaller amounts. |
| **Rapid Movement** | Tokens moving through multiple wallets quickly. |
| **High-Risk Addresses** | Interaction with known illicit addresses. |

## 13. AML/CFT and PNJC Ecosystem Integration

### 13.1. Token Contract

The PNJC token contract is **ownerless** and **non-upgradeable**, which means:
- No administrative functions exist to freeze or block addresses;
- No central authority can intervene in transactions;
- All transactions are publicly verifiable on PolygonScan.

### 13.2. Charity Reserve

The Charity Reserve (5%, 50B PNJC) is a **public wallet**, ensuring:
- All charitable transactions are on-chain and transparent;
- Funds can be traced and verified;
- Community oversight through DAO governance (Q4 2026).

### 13.3. DAO Governance

The DAO (Q4 2026) will provide:
- Community oversight of treasury and charity allocations;
- Transparent decision-making on ecosystem initiatives;
- Accountability through on-chain voting.

### 13.4. ClownCare Bridge

The ClownCare Bridge (Q2 2027) will provide:
- Transparent charitable fund distribution;
- On-chain reporting for every donation;
- Full traceability of charitable funds.
