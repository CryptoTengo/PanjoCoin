## 1. Overview

This document defines the **financial model** of PanjoCoin (PNJC).

The purpose of this model is to describe:

- Revenue generation mechanisms;
- Cost structure;
- Treasury sustainability;
- Investment requirements;
- Growth scenarios;
- Financial planning principles.

The PNJC financial model is designed around a long-term ecosystem approach:

```
Community Growth
        ↓
Product Development
        ↓
Utility Expansion (Gaming, Charity, Governance)
        ↓
Revenue Generation
        ↓
Ecosystem Sustainability
```

## 2. Financial Philosophy

PNJC follows several principles:

### Long-Term Sustainability

The ecosystem should gradually reduce dependency on external funding through utility-driven revenue.

### Multiple Revenue Streams

The project should not rely on a single income source.

**Potential sources:**
- Platform services (ONE+ gaming);
- Partnerships;
- GameFi economy;
- SocialFi applications;
- Educational products;
- Charitable programs.

### Responsible Treasury Management

Treasury resources are used for:

- Development (smart contracts, applications);
- Security (audits, testing);
- Marketing (community growth);
- Partnerships (ecosystem expansion);
- Ecosystem growth.

## 6. Treasury Model

### Treasury Purpose

The Treasury supports:

- Long-term development;
- Liquidity management;
- Security;
- Partnerships;
- Ecosystem incentives.

### Treasury Allocation

| Category | Allocation | Amount (PNJC) | Control |
| :--- | :--- | :--- | :--- |
| **Operational Treasury** | 12% | 120,000,000,000 | 3/5 Multisig |
| **DAO Treasury** | 10% | 100,000,000,000 | DAO (Q4 2026) |
| **Charity Reserve** | 5% | 50,000,000,000 | Public wallet |

### Treasury Control

- **Operational Treasury:** 3/5 multisig until DAO launch.
- **DAO Treasury:** Controlled by community voting after Q4 2026.
- **Charity Reserve:** Public wallet with on-chain transparency.

## 10. Unit Economics

### Customer Acquisition Cost (CAC)

Cost required to acquire a new user.

**Includes:**
- Marketing spend;
- Airdrop costs;
- Referral incentives.

### Lifetime Value (LTV)

Estimated value generated by a user.

**Includes:**
- Transaction fees;
- Service subscriptions;
- In-game purchases;
- Platform activity.

### LTV/CAC Ratio

**Target:**
```
LTV > CAC
```

**Meaning:** Users generate more value than acquisition cost.
