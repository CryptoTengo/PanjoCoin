# 10. Unit Economics

Important indicators:

## Customer Acquisition Cost (CAC)

Cost required to acquire a new user.

---

## Lifetime Value (LTV)

Estimated value generated by a user.

---

## LTV/CAC Ratio

Target:

```
LTV > CAC

```

Meaning:

Users generate more value than acquisition cost.
