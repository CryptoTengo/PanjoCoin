## 1. Overview

This document defines the **Treasury Policy** of PanjoCoin (PNJC).

The purpose of the Treasury Policy is to establish:

- Secure management of ecosystem assets;
- Transparent financial operations;
- Responsible allocation of resources;
- Long-term ecosystem sustainability;
- Protection against unauthorised access or misuse.

The PNJC Treasury operates according to:

| Principle | Description |
| :--- | :--- |
| **Transparency** | All significant movements publicly verifiable. |
| **Security** | Multisig protection, hardware wallets. |
| **Accountability** | Clear roles and approval processes. |
| **Long-Term Sustainability** | Responsible resource allocation. |

## 6. Treasury Wallet Security

Treasury funds must be stored using:

- Multisignature wallets (3/5);
- Hardware wallet protection (Ledger, Trezor);
- Secure key management;
- Limited access permissions.

**Recommended Configuration:**

```
3 of 5 Multisig Approval
```

**Meaning:**
- 5 authorised signers exist;
- Minimum 3 approvals required;
- No single person can move funds alone.

## 13. Treasury Reserve Strategy

The Treasury should maintain reserves for:

- Long-term development (12+ months runway);
- Market uncertainty;
- Security incidents;
- Emergency operations.

**Reserve Targets:**
- Operational Reserve: 12+ months of operational expenses;
- Emergency Reserve: 3-6 months of critical operations.
