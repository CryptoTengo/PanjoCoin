## 1. Overview

This document defines the **Business Model** of PanjoCoin (PNJC).

The PNJC business model describes how the ecosystem creates, captures, and distributes value through:

- Utility services;
- SocialFi mechanisms;
- GameFi economy;
- Community participation;
- Charity initiatives;
- Strategic partnerships.

**The goal:**

```
Create Sustainable Ecosystem Value
        ↓
Increase Utility (Gaming, Charity, Governance)
        ↓
Grow Community
        ↓
Support Long-Term Development
```
