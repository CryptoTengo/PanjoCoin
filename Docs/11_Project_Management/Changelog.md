## Versioning Policy

Version numbers follow Semantic Versioning where appropriate.

### Major Version

**Incremented when:**
- Breaking protocol changes.
- Major architectural redesign.
- Governance restructuring.

**Example:** `1.x.x → 2.0.0`

### Minor Version

**Incremented when:**
- New features.
- New documentation.
- New ecosystem components.

**Example:** `1.0.x → 1.1.0`

### Patch Version

**Incremented when:**
- Documentation corrections.
- Typographical fixes.
- Clarifications.
- Minor improvements.

**Example:** `1.0.0 → 1.0.1`
