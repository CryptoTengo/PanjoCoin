# 1. Overview

This document defines the Impact Framework of PanjoCoin (PNJC).

The purpose of the PNJC Impact Framework is to create a transparent and measurable system for evaluating, recording, and rewarding positive contributions within the ecosystem.

The framework connects:

- Blockchain technology
- Social impact initiatives
- Community participation
- Charity programs
- Proof of Kindness
- ESG principles


The PNJC Impact Framework is based on:


Positive Action

Verification

Measurement

Transparency

Recognition

=

Social Impact Value

# 2. Impact Mission
