# Overview

**PanjoCoin (PNJC)** is an open-source utility token built on the Polygon blockchain to support a transparent, community-driven ecosystem focused on blockchain technology, artificial intelligence, education, and social impact.

The project emphasizes long-term ecosystem development through practical utility, responsible governance, open-source development, and community participation rather than short-term speculation.
