# 1. Overview

## Building a Sustainable Token Economy

PanjoCoin (PNJC) is designed as a utility-focused ERC-20 token supporting the Panjo ecosystem.

The token economy is based on:

- fixed supply;
- transparent allocation;
- controlled token release;
- ecosystem utility;
- community participation.

The objective is to create a sustainable digital economy rather than a short-term speculative asset.
