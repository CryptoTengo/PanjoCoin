# 1. Overview

PanjoCoin (PNJC) is a community-driven utility token designed to power the CryptoTengo ecosystem.

The project combines:

- Web3 technology
- Community participation
- Proof of Kindness (PoK)
- Social Mining
- GameFi experiences
- Charity initiatives
- AI-powered content ecosystem

PNJC is designed as a utility and ecosystem participation token. It does not represent ownership, equity, shares, or guaranteed financial returns.
