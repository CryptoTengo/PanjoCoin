# 1. Overview

PanjoCoin (PNJC) is a decentralized ERC-20 utility token deployed on the Polygon PoS network.

The smart contract architecture is designed with a focus on:

- Security
- Transparency
- Decentralization
- Regulatory readiness
- Community governance
- Long-term ecosystem sustainability

The contract implements a fixed supply model with no future minting capability.
